# SIMD Operations Facade Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add allocation-free, typed whole-slice wrappers over the pinned SIMD library with a portable pure-Go backend and runtime diagnostics.

**Architecture:** `internal/simdops` exposes one bounded API to evaluator and index code. Normal builds forward whole slices to `github.com/sebishogun/simd`; `purego` builds use matching scalar loops. Narrow private unsafe views preserve defined policy ID types and uint64 bitplanes without copies.

**Tech Stack:** Go 1.27, `github.com/sebishogun/simd` v1.21.0, build tags, generic `~uint32`/`~int64` constraints, standard `unsafe` slice views.

### Task 2: Implement Shared API And Both Backends

**Files:**
- Create: `internal/simdops/ops.go`
- Create: `internal/simdops/simd.go`
- Create: `internal/simdops/purego.go`

**Step 1: Define the bounded API in `ops.go`**

```go
type Comparison uint8

const (
    Equal Comparison = iota + 1
    NotEqual
    Less
    LessEqual
    Greater
    GreaterEqual
)

func (op Comparison) Valid() bool

// Implemented in one build-selected backend:
func CompareU32[T ~uint32](dst []bool, src []T, value T, op Comparison)
func CompareI64[T ~int64](dst []bool, src []T, value T, op Comparison)
func AndWords(dst, a, b []uint64)
func OrWords(dst, a, b []uint64)
func XorWords(dst, a, b []uint64)
func AndNotWords(dst, a, b []uint64)
func AndMask(dst, a, b []bool)
func OrMask(dst, a, b []bool)
func XorMask(dst, a, b []bool)
func NotMask(dst, src []bool)
func CompressU32[T ~uint32](dst, src []T, mask []bool) int
```

Use a static `panic("simdops: invalid comparison")` before mutation for an invalid mode. Every function processes the minimum argument length.

**Step 2: Add the accelerated backend in `simd.go`**

Use `//go:build !purego`. Add private zero-copy helpers with `unsafe.SliceData` and `unsafe.Slice`:

- `~uint32` to `[]uint32` for unsigned comparisons;
- `~int64` to `[]int64` for ordered comparisons;
- `~uint32` to `[]int32` for compression, because v1.21 has generated compression kernels for int32 while compression only copies element bits; and
- `[]uint64` to `[]byte` for bitwise operations, with a checked `len(words)*8`.

Dispatch each comparison with one switch around a whole-slice library call. Forward masks directly. Do not add threshold branches: the dependency already owns measured guards.

**Step 3: Add the pure-Go backend in `purego.go`**

Use `//go:build purego`. Implement one direct loop per operation. Put the comparison switch outside each loop so there is no per-element callback or mode switch. Compression scans `min(len(src), len(mask))`, writes until `len(dst)`, preserves order, and returns the written count.

**Step 4: Verify GREEN on both backends**

Run:

```bash
go test -count=1 -timeout 60s ./internal/simdops
go test -count=1 -timeout 60s -tags=purego ./internal/simdops
```

Expected: PASS for both commands.

**Files:**

**Step 1: Implement runtime metadata**

Define:

```go
type Thresholds struct {
    CompareU32 int
    CompareI64 int
    WordBitwise int
    BoolBitwise int
    CompressU32 int
}

type RuntimeInfo struct {
    Tier string
    Description string
    PureGo bool
    Thresholds Thresholds
}

func Runtime() RuntimeInfo
```

`info.go` reads `simd.Tier`, `simd.Describe`, and `simd.KernelThreshold`. Comparison thresholds are the maximum of the six scalar-mask operations. Convert the byte bitwise threshold to words with ceiling division by eight. `simd.go` and `purego.go` each define the build-selected `const pureGo`.
