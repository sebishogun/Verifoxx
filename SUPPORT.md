# Support

Use [GitHub Issues](https://github.com/sebishogun/nornrune/issues) for
reproducible bugs and focused feature proposals. Search existing issues first
and include the NornRune version, platform, command, bounded input, actual
result, and expected result.

This project is maintained on a best-effort basis. There is no guaranteed response time,
service level, compatibility window, or individual implementation commitment.
Do not put vulnerability details in an issue; follow [SECURITY.md](SECURITY.md)
instead.
